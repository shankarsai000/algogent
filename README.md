# Algogent

Browser extension marketplace for AI agent skills across **ChatGPT, Claude, Gemini, and Meta AI**. Pay only for completed runs (Algorand; simulate by default).

|-----------|-----|
| Phase 1 | [`phase-1`](https://github.com/shankarsai000/algogent/tree/phase-1) |
| Phase 2 | [`phase-2`](https://github.com/shankarsai000/algogent/tree/phase-2) |
| Phase 3 | [`phase-3`](https://github.com/shankarsai000/algogent/tree/phase-3) |
| Phase 4 (current) | [`main`](https://github.com/shankarsai000/algogent) |

## Quick start

```bash
pnpm install
pnpm --filter @algogent/shared build
pnpm --filter @algogent/extension test
pnpm --filter @algogent/extension dev
```
