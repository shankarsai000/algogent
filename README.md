# Algogent

Browser extension marketplace for AI agent skills. Run tasks across ChatGPT, Claude, Gemini, and Meta AI from one side panel. Pay per completed run on Algorand (Phase 3).

> **Current: Phase 2 on `main`** · Milestone tag/ref: **`phase-1`** (0.1.0)

## Quick start

```bash
git clone https://github.com/shankarsai000/algogent.git
cd algogent
pnpm install
pnpm --filter @algogent/shared build
pnpm --filter @algogent/extension dev
```

Load unpacked from WXT output → open ChatGPT or Claude → run a skill.
