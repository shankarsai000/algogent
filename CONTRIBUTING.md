# Contributing to Algogent

## Development

1. Fork / branch from `main`
2. `pnpm install`
3. Implement behind a focused PR
4. Ensure `pnpm typecheck && pnpm test && pnpm lint` pass

## Commit style

Prefer Conventional Commits: `feat:`, `fix:`, `docs:`, `chore:`, `test:`, `refactor:`.

## Security

Never commit private keys, mnemonics, or API tokens. Report sensitive issues privately to the maintainer.
