## Short description (≤132 chars)

## Detailed description

Algogent turns your browser into a skill marketplace for AI agents.

- One side panel for ChatGPT, Claude, Gemini, and Meta AI
- Uses your existing logged-in sessions (no API keys required for v1 web adapters)
- Pay only when a skill run completes successfully
- Algorand Testnet settlement with developer/platform fee split (simulate mode available)

**Note:** Provider page layouts change; if a run fails, you are not charged.
